# 乐高故事书籍功能 - 需求文档

## 1. 概述

### 1.1 项目背景
创建一个乐高小镇，有故事书籍功能，让用户可以创建、管理和阅读自己的乐高主题故事书籍。

### 1.2 目标用户
- 主要用户：儿童（6-12岁）
- 次要用户：家长辅助创作

### 1.3 核心价值
- 激发儿童创造力和想象力
- 提供个性化的故事创作体验
- 培养儿童的叙事能力

#### 2.2.3 自定义人仔
- 用户上传自己的图片
- 选择乐高风格
- 调用火山引擎图生图API生成乐高风格图片
- 选择性格类型
- 选择说话方式
- 保存自定义人仔供后续复用

#### 2.2.4 创建人仔流程
1. 点击"创建人仔"按钮，弹出创建弹窗
2. 上传照片（支持JPG/PNG格式）
3. 点击"生成乐高人仔"按钮，调用图生图API
4. 预览生成的乐高风格图片
5. 输入人仓名称、性格特点、说话方式
6. 点击"创建"保存人仔

#### 2.2.5 创建人仔弹窗设计
- 复用梦想蓝图页面的样式和布局
- 左侧：图片上传区域（第一步）
- 右侧：生成结果预览区域（第二步）
- 底部：人仔属性输入（第三步）
- 保持乐高积木风格的一致性
- 性格风格和说话风格使用下拉选择框，选项与预设人仔保持一致

#### 2.2.6 人仔属性
- 人仔ID (character_id)
- 人仓名称
- 人仔图片URL
- 人设描述
- 性格类型
- 说话方式
- 创建者user_id（预设人仔为system）
- 创建时间
- 更新时间

#### 2.2.7 图片存储规则
- 预设人仔图片：保存为base64格式到本地文件
- 自定义人仔图片：通过图生图生成后，保存为base64格式到数据库
- 不使用外部URL，确保图片永久可用

### 2.3 故事角色分配

#### 2.3.1 角色类型
- 主人公（必须有且仅有一个）
- 配角（可以有多个）
- 反派（可选）
- 路人（可选）

#### 2.3.2 角色自定义
- 为每个选中的人仔分配角色
- 可以自定义角色名称（覆盖默认人仔名称）

#### 2.3.3 角色选择步骤设计
- 预设人仔显示乐高风格图片
- 已选角色卡片显示：
  - 人仔图片（16x16大小）
  - 人仓名称
  - 角色类型选择
  - 昵称输入框（小尺寸）
  - 性格风格标签
  - 说话风格标签

#### 2.4.2 自定义情节
- 文本输入：用户手动输入情节描述（最多100字）
- 语音输入：用户通过语音描述情节，系统转文字
  - 点击"语音"按钮开始录音
  - 再次点击停止录音
  - 系统自动识别语音并转为文字
  - 识别结果追加到输入框

### 2.5 故事生成

#### 2.5.1 生成规则
- 根据选中的人仔和情节生成故事
- 调用火山引擎 Doubao API 生成故事文本
- 故事长度：100-200字
- 故事风格：适合儿童阅读、轻松有趣、充满想象力

#### 2.5.2 API调用
- 接口地址：`/api/chapter/` (action=generate)
- 调用火山引擎 API：`https://ark.cn-beijing.volces.com/api/v3/chat/completions`
- 模型：`doubao-1-5-pro-32k-250115`
- 如果API调用失败，自动降级到本地Mock模板
- API_KEY: ee51832f-f233-45ec-9262-00e1d2a66ba1

#### 2.5.3 故事展示
- 人仔名称旁边显示人仔图片
- 人仔图片大小为文字的2倍
- 关键文字高亮显示（红、紫、绿、黄）
- 关键文字不超过4个字

#### 2.5.4 关键词高亮规则
- 人仓名称：红色
- 动作词：紫色
- 情感词：绿色
- 地点词：黄色

#### 2.5.5 故事展示样式
- 故事内容文字保持正常大小
- 人仔图片放大显示（比文字大2倍）
- 人仓名称旁边显示人仔图片
- 关键词高亮显示（动作、情绪、地点等）

### 2.6 章节管理

#### 2.6.1 章节信息
- 自动生成章节号（第1章、第2章...）
- 自动生成章节名称
- 章节内容

#### 2.6.2 章节状态
- 已发布：保存到书籍

#### 2.6.3 章节生成规则
- 每次生成故事都创建新章节，不覆盖现有章节
- 章节号自动递增（第1章、第2章、第3章...）
- 章节名称根据故事内容自动生成
- 新章节自动关联到当前选择的书籍
- 故事生成后自动保存为章节，无需手动点击保存
- 不再需要"存草稿"功能，所有生成的章节直接保存

### 2.7 书籍管理

#### 2.7.1 书籍创建
- 用户点击"生成书籍"
- 输入书籍名称
- 选择要包含的章节
- 生成书籍

#### 2.7.2 书籍查看
- 书籍列表页面
- 书籍详情页面（显示所有章节）
- 阅读模式

#### 2.7.3 书籍管理
- 修改书籍名称
- 删除书籍
- 查看书架（所有书籍）

#### 2.7.4 书籍选择步骤
- 第一步必须选择或创建书籍
- 可选择已有书籍进行续写
- 可创建新书籍开始创作
- 书籍选择后，后续章节将添加到该书
- 支持通过URL参数 bookId 预选书籍

#### 2.7.5 书籍详情页面设计
- 显示书籍名称和章节数量
- 章节阅读模式
- 章节导航（上一章/下一章）
- 最后一章时，"下一章"按钮变为"继续生成故事"
- 点击"继续生成故事"跳转到故事创作页面，并预选当前书籍

### 2.8 续写功能

#### 2.8.1 续写流程
- 选择要续写的书籍
- 从第一步开始（选择人仔）
- 重复完整流程
- 新章节追加到书籍

#### 2.8.2 继续生成故事功能
- 点击"继续生成故事"时，跳转到选择故事角色步骤（step=1）
- 默认选择上一章节的主人公和其他角色
- 用户可以添加或减少角色
- 主角角色（protagonist）不能被删除，但可以更换
- 继续生成故事时，生成下一个章节，而不是覆盖现有章节
- 新章节自动添加到当前书籍中
- 章节号自动递增，章节名称自动生成

### 2.9 故事分享功能

#### 2.9.1 分享方式
- 生成分享链接
- 二维码分享
- 复制链接分享

#### 2.9.2 分享权限
- 公开分享：任何人可查看

#### 2.9.3 分享管理
- 查看分享列表
- 取消分享
- 重新生成分享链接

### 2.10 家长控制功能

#### 2.10.1 使用时长控制
- 每日使用时长限制
- 使用时段限制
- 休息提醒

#### 2.10.2 内容过滤
- 敏感词过滤
- 暴力内容过滤
- 年龄分级

#### 2.10.3 家长监控
- 查看孩子创作记录
- 查看使用统计
- 接收异常提醒

#### 2.10.4 家长账户
- 绑定儿童账户
- 设置控制规则
- 解绑账户

```

查看故事 -> 保存到书籍 -> 续写章节
```

### 4.2 管理书籍流程
```
登录 -> 进入书架 -> 选择书籍 -> 查看/编辑/删除
```
