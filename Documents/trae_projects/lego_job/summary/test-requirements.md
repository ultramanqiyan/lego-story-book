### 1.2 关于API测试（5问）

**Q6：如何测试用户API？**

**回答**：用户API测试命令：

```bash
# 创建用户

  -H "Content-Type: application/json" \
  -d '{"username":"api_test_user"}'

# 更新用户
curl -X PUT https://your-domain/api/users \
  -H "Content-Type: application/json" \
```

**Q27：XSS攻击如何测试？**

**回答**：XSS攻击测试：

| 测试输入 | 预期结果 |
|----------|----------|
| `<script>alert('xss')</script>` | 转义显示，不执行 |
| `<img onerror="alert('xss')">` | 转义显示，不执行 |
| `javascript:alert('xss')` | 不执行 |

**验证**：使用textContent而非innerHTML。

**Q28：CSRF攻击如何测试？**
