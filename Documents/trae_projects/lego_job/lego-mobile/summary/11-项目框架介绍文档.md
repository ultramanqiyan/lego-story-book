# 项目框架介绍文档

## 一、概述

本文档为完全不了解LEGO Story项目的读者提供全面的项目框架介绍，帮助您快速理解项目结构、技术架构和核心概念。

## 二、项目背景

### 2.1 产品定位

LEGO Story是一款面向儿童的互动故事创作应用，具有以下特点：

| 特点 | 说明 |
|------|------|
| 目标用户 | 6-12岁儿童及其家长 |
| 核心功能 | AI辅助故事创作 |
| 特色元素 | LEGO人仔角色系统 |
| 教育价值 | 培养创造力和表达能力 |

### 2.2 产品功能

**主要功能模块：**

1. **用户系统**：简单登录，无需密码
2. **角色管理**：创建和管理故事角色
3. **书籍管理**：创建和管理故事书
4. **故事创作**：AI辅助生成故事章节
5. **谜题互动**：章节中的互动谜题
6. **分享功能**：分享故事给朋友

## 四、核心模块介绍

### 4.1 API模块

API模块负责与后端服务器通信，采用统一的客户端封装。

**模块结构：**

```
api/
├── client.js      → 基础客户端（请求、缓存、错误处理）
├── users.js       → 用户相关接口
├── characters.js  → 角色相关接口
├── books.js       → 书籍相关接口
├── chapters.js    → 章节相关接口
├── story.js       → 故事生成接口
├── puzzle.js      → 谜题相关接口
├── share.js       → 分享相关接口
└── index.js       → 统一导出
```

**使用方式：**

从统一入口导入需要的API：

```
import { usersAPI, booksAPI } from './api';
```

**核心特性：**

| 特性 | 说明 |
|------|------|
| 请求缓存 | GET请求自动缓存30秒 |
| 请求去重 | 相同请求复用结果 |
| 超时处理 | 15秒超时自动取消 |
| 错误处理 | 统一的错误格式 |

### 4.2 Context模块

Context模块管理应用的全局状态。

**三个核心Context：**

| Context | 职责 | 提供的功能 |
|---------|------|------------|
| AuthContext | 用户认证 | 登录、登出、用户信息 |
| ThemeContext | 主题管理 | 切换主题、获取颜色 |
| ToastContext | 消息提示 | 显示提示、隐藏提示 |

**使用方式：**

```
// 在组件中使用
const { user, login } = useContext(AuthContext);
const { theme, toggleTheme } = useContext(ThemeContext);
const { show } = useContext(ToastContext);
```

### 4.3 导航模块

使用React Navigation管理应用导航。

**导航结构：**

```
AppNavigator
├── Stack Navigator (主栈)
│   ├── LoadingScreen (加载页)
│   ├── LoginScreen (登录页)
│   └── MainTabs (主标签页)
│
└── MainTabs (标签导航)
    ├── HomeTab (首页)
    ├── BookshelfTab (书架)
    ├── CharactersTab (角色)
    └── SettingsTab (设置)
```

**导航方式：**

| 操作 | 方法 |
|------|------|
| 跳转页面 | navigation.navigate('PageName') |
| 返回上一页 | navigation.goBack() |
| 替换当前页 | navigation.replace('PageName') |

### 4.4 屏幕模块

每个屏幕对应一个页面，负责页面逻辑和UI渲染。

**屏幕分类：**

| 分类 | 包含屏幕 | 功能 |
|------|----------|------|
| 认证 | LoginScreen | 用户登录 |
| 首页 | HomeScreen | 功能入口 |
| 书架 | BookshelfScreen | 书籍管理 |
| 角色 | CharactersScreen | 角色管理 |
| 故事 | BookDetailScreen, StoryDirectorScreen | 故事创作 |
| 章节 | ChapterScreen | 章节阅读 |
| 设置 | SettingsScreen, ThemeSettingsScreen, ParentControlScreen | 应用设置 |
| 分享 | ShareScreen | 分享访问 |

### 4.5 组件模块

可复用的UI组件。

**主要组件：**

| 组件 | 用途 | 特点 |
|------|------|------|
| Card3D | 3D卡片展示 | 支持翻转动画 |
| CardDeck3D | 卡片组 | 支持扇形展开 |
| 各种UI组件 | 按钮、输入框等 | 统一样式 |

## 五、数据流

### 5.1 用户操作流程

```
用户操作
    │
    ▼
屏幕组件 (Screen)
    │
    ├── 调用Context方法
    │       │
    │       └── 更新全局状态
    │
    └── 调用API方法
            │
            ├── API Client处理请求
            │       │
            │       ├── 检查缓存
            │       ├── 发送请求
            │       └── 处理响应
            │
            └── 更新组件状态
                    │
                    └── 触发界面重渲染
```

### 5.2 状态更新流程

```
用户触发操作
    │
    ▼
调用Context方法
    │
    ▼
更新Context状态
    │
    ▼
通知所有消费者
    │
    ▼
相关组件重新渲染
```

## 六、主题系统

### 6.1 主题配置

应用支持浅色和深色两种主题。

**主题结构：**

```
theme/
├── colors.js     → 颜色定义
├── spacing.js    → 间距定义
└── typography.js → 字体定义
```

**颜色配置：**

| 用途 | 浅色主题 | 深色主题 |
|------|----------|----------|
| 背景 | #FFFFFF | #1A1A2E |
| 文字 | #333333 | #FFFFFF |
| 主色 | #FF6B6B | #FF6B6B |
| 辅助色 | #4ECDC4 | #4ECDC4 |

### 6.2 主题使用

```
// 获取当前主题颜色
const { colors } = useTheme();

// 应用到样式
<View style={{ backgroundColor: colors.background }}>
```

## 七、开发指南

### 7.1 新增页面步骤

1. 在 `src/screens/` 对应目录创建新文件
2. 实现页面组件
3. 在导航配置中注册页面
4. 添加必要的测试

### 7.2 新增API步骤

1. 在 `src/api/` 创建新文件
2. 实现API方法
3. 在 `src/api/index.js` 中导出
4. 添加API测试

### 7.3 新增组件步骤

1. 在 `src/components/` 创建组件文件
2. 实现组件逻辑和样式
3. 导出组件
4. 添加组件测试

## 十、快速上手

### 10.1 环境准备

1. 安装Node.js（18.x+）
2. 安装Git
3. 安装Expo CLI：`npm install -g expo-cli`

```

# 进入目录
```
