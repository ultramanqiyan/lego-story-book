# 乐高故事书 APP 子系统设计文档

## 一、子系统划分概述

乐高故事书APP根据功能职责划分为以下几个子系统：

```
┌─────────────────────────────────────────────────────────────┐
│                    乐高故事书 APP                            │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐        │
│  │  认证子系统  │  │  书籍子系统  │  │  角色子系统  │        │
│  └─────────────┘  └─────────────┘  └─────────────┘        │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐        │
│  │  章节子系统  │  │  解谜子系统  │  │  设置子系统  │        │
│  └─────────────┘  └─────────────┘  └─────────────┘        │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐        │
│  │  UI组件系统  │  │  动画特效系统 │  │  导航系统   │        │
│  └─────────────┘  └─────────────┘  └─────────────┘        │
└─────────────────────────────────────────────────────────────┘
```

---

## 二、认证子系统

### 2.1 子系统职责
- 用户登录验证
- 用户注册处理
- 登录状态管理
- 自动登录支持
- 家长验证功能

### 2.2 核心功能

| 功能模块 | 描述 | 输入 | 输出 |
|---------|------|------|------|
| 登录 | 验证用户身份 | 用户名、密码 | 登录状态、用户信息 |
| 注册 | 创建新用户 | 用户名、密码 | 注册结果 |
| 自动登录 | 恢复登录状态 | 本地存储的凭证 | 登录状态 |
| 家长验证 | 验证家长身份 | 数学计算题 | 验证结果 |

### 2.3 与其他子系统关系

```
认证子系统
    │
    ├──▶ 书籍子系统：提供用户身份
    │
    ├──▶ 设置子系统：提供家长验证
    │
    └──▶ 导航系统：控制页面跳转
```

---

## 三、书籍子系统

### 3.1 子系统职责
- 书籍列表管理
- 书籍创建和删除
- 书籍详情展示
- 书籍分享功能

### 3.2 核心功能

| 功能模块 | 描述 | 输入 | 输出 |
|---------|------|------|------|
| 获取书籍列表 | 获取用户所有书籍 | 用户ID | 书籍列表 |
| 创建书籍 | 创建新故事书 | 书名、描述 | 新书籍信息 |
| 删除书籍 | 删除指定书籍 | 书籍ID | 删除结果 |
| 获取书籍详情 | 获取书籍完整信息 | 书籍ID | 书籍详情 |

### 3.3 与其他子系统关系

```
书籍子系统
    │
    ├──▶ 角色子系统：管理书籍中的角色
    │
    ├──▶ 章节子系统：管理书籍中的章节
    │
    └──▶ 认证子系统：获取用户身份
```

---

## 四、角色子系统

### 4.1 子系统职责
- 角色创建和管理
- 角色类型分类（主角、配角、反派）
- 角色选择功能
- 角色展示功能

### 4.2 核心功能

| 功能模块 | 描述 | 输入 | 输出 |
|---------|------|------|------|
| 获取角色列表 | 获取书籍所有角色 | 书籍ID | 角色列表 |
| 创建角色 | 创建新角色 | 角色信息 | 新角色数据 |
| 更新角色 | 修改角色信息 | 角色ID、更新数据 | 更新结果 |
| 删除角色 | 删除角色 | 角色ID | 删除结果 |

### 4.3 角色类型说明

| 类型 | 标识 | 描述 | 视觉特征 |
|------|------|------|---------|
| 主角 | protagonist | 故事主要人物 | 金色边框 |
| 配角 | supporting | 辅助角色 | 银色边框 |
| 反派 | antagonist | 对立角色 | 红色边框 |

---

## 五、章节子系统

### 5.1 子系统职责
- 章节创建和管理
- 章节内容生成
- 章节阅读功能
- 阅读进度跟踪

### 5.2 核心功能

| 功能模块 | 描述 | 输入 | 输出 |
|---------|------|------|------|
| 获取章节列表 | 获取书籍所有章节 | 书籍ID | 章节列表 |
| 创建章节 | 创建新章节 | 章节信息 | 新章节数据 |
| 生成章节内容 | AI生成故事内容 | 角色信息、场景 | 故事文本 |
| 保存阅读进度 | 记录阅读位置 | 用户ID、章节ID | 保存结果 |

### 5.3 与其他子系统关系

```
章节子系统
    │
    ├──▶ 角色子系统：获取章节涉及的角色
    │
    ├──▶ 解谜子系统：管理章节中的解谜
    │
    └──▶ 书籍子系统：关联所属书籍
```

---

## 六、解谜子系统

### 6.1 子系统职责
- 解谜题目管理
- 答案验证
- 提示功能
- 解谜进度跟踪

### 6.2 核心功能

| 功能模块 | 描述 | 输入 | 输出 |
|---------|------|------|------|
| 获取解谜 | 获取章节解谜题目 | 章节ID | 解谜内容 |
| 提交答案 | 验证用户答案 | 解谜ID、答案 | 验证结果 |
| 获取提示 | 提供解题提示 | 解谜ID | 提示内容 |
| 跳过解谜 | 跳过当前解谜 | 解谜ID | 跳过结果 |

### 6.3 解谜类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 选择题 | 四选一答案 | A/B/C/D选项 |
| 判断题 | 是非判断 | 正确/错误 |

### 7.1 子系统职责

- API环境切换
- 家长控制功能
- 用户信息管理

### 7.2 核心功能

| 功能模块 | 描述 | 输入 | 输出 |

## 八、UI组件系统

### 8.1 子系统职责
- 提供可复用的UI组件
- 统一视觉风格
- 组件状态管理
- 动画效果支持

### 8.2 组件分类

| 分类 | 组件 | 用途 |
|------|------|------|
| 基础组件 | Button、Card、Header | 通用UI元素 |
| 表单组件 | Input、Select、Checkbox | 数据输入 |
| 展示组件 | List、Grid、Carousel | 内容展示 |
| 反馈组件 | Toast、Modal、Loading | 用户反馈 |

### 8.3 组件设计原则

- **可复用性**：组件可在多个页面复用
- **可配置性**：通过属性定制组件外观和行为
- **一致性**：统一的设计语言和交互方式
- **可访问性**：支持无障碍访问

---

## 九、动画特效系统

### 9.1 子系统职责
- 3D卡牌动画
- 天气特效渲染
- 粒子动画效果
- 页面转场动画

### 9.2 特效类型

| 特效类型 | 描述 | 应用场景 |
|---------|------|---------|
| 3D翻转 | 卡牌翻转效果 | 角色卡牌 |
| 扇形展开 | 卡牌扇形排列 | 卡牌组展示 |
| 天气效果 | 雨、雪、晴天 | 舞台预览 |
| 粒子效果 | 魔法粒子 | 背景装饰 |

### 9.3 性能考虑

- 使用原生动画驱动
- 避免JS线程阻塞
- 合理控制粒子数量
- 支持动画开关

## 十、导航系统

### 10.1 子系统职责
- 页面路由管理
- 导航栈管理
- 深度链接支持
- 页面参数传递

### 10.2 导航结构

```
根导航
├── 认证导航
│   └── 登录页面
└── 主导航
    ├── Tab导航
    │   ├── 首页
    │   ├── 书架
    │   └── 设置
    └── Stack导航
        ├── 书籍详情
        ├── 角色管理
        ├── 故事导演台
        └── 章节阅读
```

### 10.3 导航特性

| 特性 | 描述 |
|------|------|
| 嵌套导航 | Tab与Stack导航组合 |
| 页面缓存 | 保持页面状态 |
| 转场动画 | 页面切换动画 |
| 参数传递 | 页面间数据传递 |

---

## 十一、子系统间通信

### 11.1 通信方式

| 方式 | 用途 | 示例 |
|------|------|------|
| Context | 全局状态共享 | 用户登录状态 |
| Props | 父子组件通信 | 组件属性传递 |
| Callback | 子父组件通信 | 事件回调 |
| Navigation | 页面间通信 | 页面参数传递 |

### 11.2 数据流向

```
用户操作
    │
    ▼
UI组件
    │
    ▼
业务逻辑层
    │
    ├──▶ 本地存储
    │
    └──▶ 网络请求
         │
         ▼
      后端服务
```
