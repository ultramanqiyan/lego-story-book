# API接口文档

## 一、概述

LEGO Story APP通过API与后端服务器通信，实现用户管理、故事创作、人仔管理等功能。本文档详细介绍各个API模块的功能和使用方式。

## 二、API客户端架构

### 2.1 基础配置

APP使用统一的API客户端进行网络请求，具有以下特点：

| 配置项 | 说明 |
|--------|------|
| 基础地址 | Web端使用 localhost:8788，移动端使用 10.0.2.2:8788 |
| 缓存时长 | 30秒内相同请求使用缓存 |
| 请求超时 | 15秒超时限制 |
| 缓存容量 | 最多缓存50个请求结果 |

### 2.2 核心功能

- **请求缓存**：GET请求自动缓存，减少重复请求
- **请求去重**：相同请求正在进行时，复用结果
- **超时处理**：自动取消超时请求
- **错误处理**：统一处理网络错误和服务器错误

### 2.3 支持的请求方法

| 方法 | 用途 | 是否缓存 |
|------|------|----------|
| GET | 获取数据 | 是 |
| POST | 创建数据 | 否 |
| PUT | 更新数据 | 否 |
| DELETE | 删除数据 | 否 |

## 三、API模块详解

### 3.1 用户模块 (usersAPI)

用户模块负责用户账号的创建、登录和信息管理。

#### 功能列表

| 功能 | 方法 | 说明 |
|------|------|------|
| 创建或登录 | createOrLogin | 通过用户名创建新用户或登录已有用户 |
| 获取用户信息 | getUser | 获取指定用户的详细信息 |
| 更新用户信息 | updateUser | 更新用户的名称、头像等资料 |

#### 使用场景

1. **首次使用**：用户输入用户名，系统自动创建账号
2. **再次使用**：用户输入相同用户名，自动登录获取之前的数据
3. **个人设置**：用户修改头像、设置每日使用时间限制

#### 数据字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | 文本 | 是 | 用户名，最多20字符 |
| email | 文本 | 否 | 邮箱地址 |
| avatar | 文本 | 否 | 头像图片地址 |
| dailyTimeLimit | 数字 | 否 | 每日使用时间限制（分钟） |

---

### 3.2 人仔模块 (charactersAPI)

人仔模块管理故事中的角色人物。

#### 功能列表

| 功能 | 方法 | 说明 |
|------|------|------|
| 获取人仔列表 | getList | 获取用户创建的人仔或公开人仔 |
| 创建人仔 | create | 创建新的角色人仔 |
| 更新人仔 | update | 修改人仔的属性信息 |
| 删除人仔 | delete | 删除人仔（可强制删除） |

#### 人仔属性说明

| 属性 | 类型 | 说明 |
|------|------|------|
| name | 文本 | 人仔名称，最多20字符 |
| imageBase64 | 文本 | 人仔图片的Base64编码 |
| description | 文本 | 人仔描述 |
| personality | 文本 | 性格特点 |
| speakingStyle | 文本 | 说话方式 |

#### 使用场景

1. **创建角色**：在角色管理页面创建新的故事角色
2. **编辑角色**：修改角色的性格、说话方式等属性
3. **删除角色**：移除不再需要的角色

---

### 3.3 书籍模块 (booksAPI)

书籍模块管理用户创作的故事书。

#### 功能列表

| 功能 | 方法 | 说明 |
|------|------|------|
| 获取书籍列表 | getList | 获取用户的所有故事书 |
| 获取书籍详情 | getDetail | 获取单本书的详细信息 |
| 创建书籍 | create | 创建新的故事书 |
| 更新书籍 | update | 修改书籍标题或状态 |
| 删除书籍 | delete | 删除故事书 |

#### 书籍状态

| 状态 | 说明 |
|------|------|
| active | 进行中 |
| completed | 已完成 |
| archived | 已归档 |

---

### 3.4 书籍角色模块 (bookCharactersAPI)

书籍角色模块管理书籍中的角色分配。

#### 功能列表

| 功能 | 方法 | 说明 |
|------|------|------|
| 获取书籍角色 | getList | 获取某本书的所有角色 |
| 添加角色 | add | 将人仔添加到书籍中 |
| 更新角色 | update | 修改角色在书中的设定 |
| 移除角色 | delete | 从书中移除角色 |

#### 角色类型

| 类型 | 英文 | 说明 |
|------|------|------|
| 主角 | protagonist | 故事的主要角色 |
| 反派 | antagonist | 故事的对手角色 |
| 配角 | supporting | 重要的辅助角色 |
| 龙套 | extra | 次要的小角色 |

### 3.5 章节模块 (chaptersAPI)

章节模块管理故事书的章节内容。

#### 功能列表

| 功能 | 方法 | 说明 |
|------|------|------|
| 获取章节详情 | getDetail | 获取单个章节的内容 |
| 获取章节列表 | getListByBook | 获取书籍的所有章节 |
| 创建章节 | create | 创建新章节 |
| 删除章节 | delete | 删除章节 |
| 标记完成 | complete | 标记章节为已阅读 |
| 生成章节 | generate | AI自动生成新章节 |

#### 章节生成参数

| 参数 | 类型 | 说明 |
|------|------|------|
| plotSelection | 对象 | 情节选择（天气、地形等） |
| characterIds | 数组 | 参与本章的角色ID列表 |

### 3.6 故事生成模块 (storyAPI)

故事生成模块负责AI故事内容的生成。

#### 功能列表

| 功能 | 方法 | 说明 |
|------|------|------|
| 生成故事 | generate | 根据参数生成故事章节 |

#### 生成参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| characters | 数组 | 参与故事的角色列表 |
| plot | 文本 | 情节类型 |
| previousSummary | 文本 | 前情提要 |
| plotSelection | 对象 | 情节选择（天气、冒险类型等） |
| forcePuzzle | 布尔 | 是否强制生成谜题 |

#### 情节选择选项

| 类别 | 可选项 |
|------|--------|
| 天气 | 晴天、雨天、雪天、暴风雨等 |
| 冒险类型 | 探险、解谜、救援、寻宝等 |
| 地形 | 森林、沙漠、海洋、山脉等 |
| 装备 | 魔法道具、交通工具、武器等 |

---

### 3.7 谜题模块 (puzzleAPI)

谜题模块管理故事中的互动谜题。

#### 功能列表

| 功能 | 方法 | 说明 |
|------|------|------|
| 获取谜题 | getById | 通过ID获取谜题 |
| 通过章节获取 | getByChapter | 获取章节中的谜题 |

| 字段 | 说明 |
|------|------|

## 四、错误处理

### 4.1 常见错误类型

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| 网络连接失败 | 无网络或服务器不可达 | 检查网络连接 |
| 请求超时 | 服务器响应过慢 | 稍后重试 |
| 服务器返回格式错误 | 服务器异常 | 联系管理员 |
| 参数错误 | 缺少必填参数 | 检查输入 |

### 4.2 错误处理流程

1. 检测网络状态
2. 显示友好的错误提示
3. 提供重试选项
4. 记录错误日志

## 五、使用建议

### 5.1 性能优化

- 合理使用缓存，避免重复请求
- 批量操作时合并请求
- 大文件上传使用分片传输

### 5.2 安全建议

- 敏感数据使用HTTPS传输
- 用户Token定期刷新
- 重要操作需要二次确认
