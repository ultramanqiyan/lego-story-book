# 类调用链图文档

## 一、概述

本文档描述LEGO Story APP中各功能模块的调用链路，帮助读者理解数据如何在不同组件之间流转。

## 二、应用启动调用链

### 2.1 应用初始化流程

```
App.js (应用入口)
    │
    ├── 1. 加载字体资源
    │       └── Font.loadAsync()
    │
    ├── 2. 初始化主题
    │       └── ThemeProvider
    │               └── 读取本地存储的主题设置
    │
    ├── 3. 初始化提示系统
    │       └── ToastProvider
    │
    ├── 4. 初始化认证状态
    │       └── AuthProvider
    │               └── 检查本地存储的用户信息
    │
    └── 5. 渲染导航
            └── NavigationContainer
                    └── Stack.Navigator
                            └── 各屏幕组件
```

### 2.2 启动时序

| 步骤 | 执行内容 | 耗时参考 |
|------|----------|----------|
| 1 | 加载资源文件 | 1-2秒 |
| 2 | 初始化Context | <100毫秒 |
| 3 | 检查登录状态 | <100毫秒 |
| 4 | 渲染首屏 | <500毫秒 |

## 三、用户认证调用链

### 3.1 用户登录流程

```
LoginScreen (登录界面)
    │
    ├── 用户输入用户名
    │
    ├── 点击登录按钮
    │       │
    │       └── handleLogin() 方法
    │               │
    │               ├── 调用 AuthContext.login(username)
    │               │       │
    │               │       ├── 调用 usersAPI.createOrLogin(username)
    │               │       │       │
    │               │       │       └── apiClient.post('/users', body)
    │               │       │               │
    │               │       │               ├── 构建请求URL
    │               │       │               ├── 设置请求头
    │               │       │               ├── 发送HTTP请求
    │               │       │               └── 处理响应
    │               │       │
    │               │       ├── 保存用户信息到本地
    │               │       └── 更新用户状态
    │               │
    │               └── 导航到主页
    │
    └── 显示主页内容
```

### 3.2 登录状态检查

```
AuthProvider (认证提供者)
    │
    ├── 应用启动时
    │       │
    │       └── 检查 AsyncStorage 中的用户ID
    │               │
    │               ├── 有用户ID
    │               │       └── 调用 usersAPI.getUser(userId)
    │               │               └── 恢复登录状态
    │               │
    │               └── 无用户ID
    │                       └── 显示登录界面
    │
    └── 提供用户状态给子组件
```

## 十、错误处理调用链

### 10.1 API错误处理

```
任意API调用
    │
    ├── apiClient.request() 方法
    │       │
    │       ├── 发送请求
    │       │
    │       └── 捕获错误
    │               │
    │               ├── 网络错误
    │               │       └── 抛出 "网络连接失败"
    │               │
    │               ├── 超时错误
    │               │       └── 抛出 "请求超时"
    │               │
    │               ├── 服务器错误
    │               │       └── 抛出服务器返回的错误信息
    │               │
    │               └── 解析错误
    │                       └── 抛出 "服务器返回格式错误"
    │
    └── 调用方捕获错误
            │
            └── ToastContext.show(error, 'error')
                    │
                    └── 显示错误提示
```

### 10.2 全局错误边界

## 十一、性能优化调用链

### 11.1 请求缓存

```
apiClient.get() 方法
    │
    ├── 生成缓存键
    │       └── getCacheKey(endpoint, options)
    │
    ├── 检查缓存
    │       │
    │       ├── 缓存存在且未过期
    │       │       └── 直接返回缓存数据
    │       │
    │       └── 缓存不存在或已过期
    │               └── 发送实际请求
    │
    └── 更新缓存
            └── setCache(key, data)
```

### 11.2 请求去重

```
apiClient.request() 方法
    │
    ├── 检查是否有相同请求正在进行
    │       │
    │       ├── 有
    │       │       └── 返回现有请求的Promise
    │       │
    │       └── 无
    │               └── 创建新请求
    │                       │
    │                       ├── 存储到 pendingRequests
    │                       │
    │                       └── 请求完成后移除
```
