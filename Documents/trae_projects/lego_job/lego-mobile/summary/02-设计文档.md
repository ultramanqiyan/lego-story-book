# 乐高故事书 APP 设计文档

## 一、整体架构设计

### 1.1 应用架构概览

乐高故事书APP采用经典的移动应用三层架构：

```
┌─────────────────────────────────────────┐
│              展示层 (UI)                 │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐   │
│  │  页面   │ │  组件   │ │  导航   │   │
│  └─────────┘ └─────────┘ └─────────┘   │
├─────────────────────────────────────────┤
│              业务逻辑层                  │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐   │
│  │  Context │ │  Hooks  │ │  API    │   │
│  └─────────┘ └─────────┘ └─────────┘   │
├─────────────────────────────────────────┤
│              数据层                      │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐   │
│  │ 本地存储 │ │ 网络请求 │ │ 状态管理 │   │
│  └─────────┘ └─────────┘ └─────────┘   │
└─────────────────────────────────────────┘
```

### 1.2 技术选型

| 技术领域 | 选择方案 | 选择原因 |
|---------|---------|---------|
| 框架 | React Native + Expo | 跨平台开发，快速迭代 |
| 导航 | React Navigation | 成熟的导航解决方案 |
| 动画 | React Native Reanimated | 高性能原生动画 |
| 状态管理 | React Context + Zustand | 轻量级，易于使用 |
| 网络请求 | Axios | 功能完善，拦截器支持 |
| 本地存储 | AsyncStorage + SecureStore | 安全可靠的存储方案 |

## 二、UI/UX设计原则

### 2.1 设计理念

**乐高风格**：整个APP的设计灵感来源于乐高积木，强调：
- 明亮活泼的色彩
- 圆角矩形元素
- 积木堆叠感
- 儿童友好的交互

### 2.2 色彩系统

| 颜色名称 | 用途 | 视觉效果 |
|---------|------|---------|
| 乐高黄 | 主色调、强调元素 | 温暖、活力 |
| 乐高蓝 | 次要元素、信息展示 | 稳重、信任 |
| 乐高红 | 警告、重要操作 | 醒目、警示 |
| 乐高绿 | 成功、确认 | 积极、正向 |
| 背景灰 | 页面背景 | 柔和、舒适 |

### 2.3 字体规范

| 类型 | 大小 | 用途 |
|------|------|------|
| 大标题 | 24px | 页面标题 |
| 标题 | 18px | 区块标题 |
| 正文 | 14px | 主要内容 |
| 小字 | 12px | 辅助信息 |

### 2.4 间距规范

| 名称 | 数值 | 用途 |
|------|------|------|
| 大间距 | 24px | 区块间隔 |
| 中间距 | 16px | 元素间隔 |
| 小间距 | 8px | 紧凑元素 |
| 微间距 | 4px | 内部间距 |

## 三、页面流程设计

### 3.1 整体导航流程

```
启动APP
    │
    ▼
┌─────────┐    未登录    ┌─────────┐
│ 加载页面 │ ──────────▶ │ 登录页面 │
└─────────┘              └─────────┘
    │                        │
    │ 已登录                  │ 登录成功
    ▼                        ▼
┌─────────────────────────────────┐
│           主页面 (Tab导航)        │
│  ┌────────┐ ┌────────┐ ┌────────┐│
│  │  首页  │ │  书架  │ │  设置  ││
│  └────────┘ └────────┘ └────────┘│
└─────────────────────────────────┘
         │           │
         ▼           ▼
    ┌─────────┐  ┌─────────┐
    │ 故事详情 │  │ 角色管理 │
    └─────────┘  └─────────┘
         │
         ▼
    ┌─────────┐
    │ 章节阅读 │
    └─────────┘
```

### 3.2 主要页面说明

| 页面名称 | 功能描述 | 入口 |
|---------|---------|------|
| 加载页面 | 显示启动动画，检查登录状态 | 应用启动 |
| 登录页面 | 用户登录或注册 | 未登录时 |
| 首页 | 展示功能入口和快捷操作 | Tab导航 |
| 书架页面 | 管理故事书籍 | Tab导航 |
| 设置页面 | 应用设置和主题切换 | Tab导航 |
| 故事详情 | 展示故事信息和章节列表 | 点击书籍 |
| 角色管理 | 创建和管理故事角色 | 故事详情页 |
| 故事导演台 | 编写故事章节 | 故事详情页 |
| 章节阅读 | 阅读故事和互动解谜 | 点击章节 |

## 四、交互设计说明

### 4.1 手势交互

| 手势 | 用途 | 应用场景 |
|------|------|---------|
| 点击 | 选择、确认 | 按钮、列表项 |
| 长按 | 删除、编辑 | 书籍、角色卡片 |
| 滑动 | 切换、删除 | 页面切换、删除确认 |
| 拖拽 | 排序、移动 | 角色排序 |

### 4.2 反馈机制

| 操作类型 | 反馈方式 | 示例 |
|---------|---------|------|
| 点击按钮 | 缩放动画 + 触觉反馈 | 创建按钮点击 |
| 操作成功 | Toast提示 | 创建成功提示 |
| 操作失败 | 弹窗提示 | 网络错误提示 |
| 加载中 | Loading动画 | 数据加载 |

### 4.3 动画效果

| 动画类型 | 用途 | 时长 |
|---------|------|------|
| 淡入淡出 | 页面切换 | 300ms |
| 缩放 | 按钮点击 | 100ms |
| 滑动 | 列表展开 | 200ms |
| 3D翻转 | 卡牌翻转 | 600ms |

## 五、组件设计规范

### 5.1 基础组件

| 组件名称 | 用途 | 可定制属性 |

## 六、响应式设计

### 6.1 屏幕适配

| 屏幕类型 | 宽度范围 | 适配策略 |
|---------|---------|---------|
| 小屏手机 | < 360px | 减少列数，缩小字体 |
| 标准手机 | 360px - 420px | 标准布局 |
| 大屏手机 | > 420px | 增加间距，放大元素 |
| 平板 | > 600px | 双列布局 |

### 6.2 横竖屏适配

- 默认竖屏使用
- 阅读页面支持横屏
- 设置页面锁定竖屏

## 七、无障碍设计

### 7.1 可访问性

| 功能 | 实现方式 |
|------|---------|
| 屏幕阅读器 | 为所有元素添加无障碍标签 |
| 颜色对比 | 确保文字与背景对比度达标 |
| 触摸目标 | 按钮最小触摸区域44x44像素 |
| 动画开关 | 支持关闭动画效果 |

### 7.2 儿童友好设计

- 大按钮、大字体
- 简洁的界面布局
- 友好的错误提示
- 防误触设计
