# 卡牌风格和动画效果使用指南

## 🎨 功能说明

本应用实现了10种卡牌风格和10种动画效果，可以实时切换并查看效果。

## 📍 按钮位置

在游戏界面底部，你会看到三个圆形按钮：

1. **🎨 风格按钮** - 左侧，棕色背景，金色边框，带发光效果
2. **结束回合按钮** - 中间，金色背景
3. **✨ 动画按钮** - 右侧，棕色背景，金色边框，带发光效果

## 🎮 如何使用

### 切换卡牌风格

1. 点击底部的 **🎨 风格** 按钮或 **✨ 动画** 按钮
2. 会弹出一个设置面板
3. 在"卡牌风格"区域，横向滑动查看所有风格
4. 点击任意风格即可切换

### 切换动画效果

1. 点击底部的 **🎨 风格** 按钮或 **✨ 动画** 按钮
2. 在弹出的设置面板中，找到"动画效果"区域
3. 横向滑动查看所有动画
4. 点击任意动画即可切换

## 🎯 测试建议

1. **风格测试**：依次点击每种风格，观察卡牌颜色、边框、阴影的变化
2. **动画测试**：切换不同动画后，打出卡牌或召唤随从，观察入场动画
3. **组合测试**：尝试不同风格+动画的组合，找到最喜欢的搭配

## 🔧 技术实现

- **StyleContext**: 管理全局风格和动画状态
- **CARD_STYLES**: 定义所有卡牌风格配置
- **ANIMATION_CONFIGS**: 定义所有动画配置
- **AnimationEffects**: 实现各种动画效果
- **StyleSelector**: 风格选择器UI组件
