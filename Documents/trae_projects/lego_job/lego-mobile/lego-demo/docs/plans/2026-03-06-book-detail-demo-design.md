# 书籍详情页Demo设计方案

## 概述

本文档记录书籍详情页Demo的设计方案，提供**多种风格**可选，默认采用**书本风格**，模拟真实书籍翻页体验。

## 参考文件

- 原始实现：`lego-mobile/src/screens/story/BookDetailScreen.js`
- 章节内容：`lego-mobile/src/screens/chapter/ChapterScreen.js`
- 设计参考：`lego-demo/src/screens/StoryDirectorDemo.tsx`

---

## 核心功能

### 页面展示内容

1. **书籍名称** - Header区域显示
2. **章节列表** - 目录形式展示（默认展示）
3. **章节内容** - 点击章节后在页面内显示内容
4. **角色信息** - 书籍中的角色列表
5. **情节卡牌** - 天气、冒险类型、地形、装备卡牌

### 数据结构

```typescript
// 书籍
interface Book {
  bookId: string;
  title: string;
}

// 章节
interface Chapter {
  chapterId: string;
  chapterNumber: number;
  title: string;
  content: string;
  wordCount: number;
  hasPuzzle: boolean;
  puzzleResult?: 0 | 1;
  characters: string[];
  puzzle?: {
    question: string;
    options: string[];
    correctIndex: number;
    attempts: number;
    maxAttempts: number;
  };
}

// 角色
interface BookCharacter {
  id: string;
  customName: string;
  name: string;
  roleType: 'protagonist' | 'supporting' | 'antagonist';
  emoji: string;
  description: string;
}

// 情节卡牌
interface PlotCard {
  id: string;
  type: 'weather' | 'adventure' | 'terrain' | 'equipment';
  name: string;
  emoji: string;
  description: string;
}
```

## 风格方案

### 风格对比

| 风格 | 特点 | 适用场景 |
|------|------|----------|
| **风格A：经典书籍风格** | 模拟真实书籍翻页效果 | 传统阅读体验 |
| **风格B：卡牌游戏风格** | 卡牌布局、游戏化元素 | 游戏化阅读 |
| **风格C：卷轴古风** | 古代卷轴展开效果 | 古风/武侠故事 |
| **风格D：杂志期刊风格** | 现代杂志排版布局 | 现代/都市故事 |
| **风格E：漫画分镜风格** | 漫画格子布局 | 冒险/动作故事 |

## 翻页逻辑

### 章节Tab翻页逻辑

```
1. 初始状态：
   - 左页：目录列表
   - 右页：上次阅读的章节内容

2. 点击目录中的章节：
   - 右页切换为该章节内容
   - 左页保持目录

3. 点击"下一页"翻页：
   - 如果章节内容还有下一页：
     - 左页：章节内容（前半部分）
     - 右页：章节内容（后半部分，含谜题）
   - 如果章节内容结束：
     - 左页：目录
     - 右页：下一章节内容

4. 点击"上一页"翻页：
   - 如果当前在章节中间：
     - 显示上一页内容
   - 如果当前在章节开头：
     - 左页：目录
     - 右页：上一章节内容
```

```typescript
const pageFlipConfig = {
  duration: 600,           // 动画时长600ms

    to: -180,              // 结束角度（向左翻转）
  },
  transformOrigin: 'left center',  // 旋转中心点
```

## 阅读位置记忆

### 存储方案

```typescript
const READING_POSITION_KEY = 'book_reading_position';

interface ReadingPosition {
  bookId: string;
  chapterId: string;
  timestamp: number;
}

const saveReadingPosition = async (bookId: string, chapterId: string) => {
  await AsyncStorage.setItem(
    READING_POSITION_KEY,
    JSON.stringify({ bookId, chapterId, timestamp: Date.now() })
  );
};

const getReadingPosition = async (bookId: string): Promise<string | null> => {
  const data = await AsyncStorage.getItem(READING_POSITION_KEY);
  if (data) {
    const position: ReadingPosition = JSON.parse(data);
    if (position.bookId === bookId) {
      return position.chapterId;
    }
  }
  return null;
};
```
