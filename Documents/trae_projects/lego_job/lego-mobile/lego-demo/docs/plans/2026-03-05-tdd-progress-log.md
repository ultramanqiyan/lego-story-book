## 关键经验教训

### 1. React Native测试环境配置

**问题：** React hooks在Jest测试环境中无法正常工作

**原因：**
- React Native的测试环境需要特殊配置
- 需要mock很多原生模块
- Context Provider的嵌套导致问题

**解决方案：**
1. **优先使用Appium端到端测试** - 更接近真实环境
2. **单元测试专注于工具函数** - 避免复杂的组件测试
3. **集成测试使用真实设备/模拟器** - 验证完整功能

### 2. TDD流程调整

**原计划：** 单元测试 → 功能实现 → 重构

**调整后：**
1. 编写测试用例（文档化需求）
2. 实现功能代码
3. 使用Appium进行端到端测试
4. 检查崩溃日志
5. 迭代优化

### 3. 文档驱动开发

**重要性：**
- 详细记录每个阶段的问题和解决方案
- 方便后续复盘和学习
- 避免重复踩坑
