## 动画效果分配

### 使用的动画（效果明显）

| 元素 | 动画类型 | 效果描述 |
|------|----------|----------|
| 角色卡片 | BOUNCE | 弹跳进入，选中时缩放 |
| 冒险卡片 | FLIP | 翻转进入效果 |
| 天气卡片 | GLOW_RING | 光环呼吸效果 |
| 地形卡片 | PULSE | 脉冲缩放效果 |
| 装备卡片 | WAVE | 波浪浮动效果 |
| 舞台角色 | SHAKE | 轻微摇晃，增加动感 |
| 拍摄按钮 | SPIN + 缩放 | 点击时旋转+放大 |

### 不使用的动画（效果不明显）

| 动画类型 | 原因 |
|----------|------|
| FADE_BLINK | 渐变闪烁不够明显 |
| PARTICLE_BURST | 粒子效果在移动端不明显 |
| SLIDE | 滑入效果过于简单 |

## 交互流程

1. 用户进入页面，角色和冒险卡片以动画方式进入
2. 选择角色时，卡片弹跳并显示选中状态
3. 选择冒险/天气/地形/装备时，对应卡片显示动画效果
4. 舞台预览区实时显示选中的角色，带轻微摇晃动画
5. 点击"开始拍摄"按钮，触发旋转动画并显示提示

## 实现要点

1. 使用 `StyleContext` 管理全局风格
2. 使用 `Animated` API 实现所有动画
3. 使用 `useRef` 管理动画值，避免重渲染
4. 卡片选择使用单选模式（角色除外，最多选5个）
5. 舞台预览区根据选中项动态渲染
