# 书籍详情页 UI 重构设计方案

## 一、概述

本文档描述书籍详情页（BookDetailDemo）的UI重构方案，主要改进包括：
- 章节Tab改为目录视图+内容视图分离
- 角色Tab改为卡牌网格布局
- 情节Tab改为分类卡牌网格布局
- 扩充假数据以展示翻页效果

---

- `✅`：谜题已解答正确
- `🧩`：有谜题未解答
- `○`：无谜题，未阅读
- `🔒`：锁定状态

- 底部显示"上一页"、"页码"、"下一页"按钮

- 最后一页时"下一页"禁用

- 显示在目录最后一项

## 七、技术实现要点

### 7.1 章节内容分页算法

```typescript
const CONTENT_PAGE_HEIGHT = 400; // 每页内容高度（像素）
const LINE_HEIGHT = 22;          // 行高
const CHARS_PER_LINE = 20;       // 每行约20个字符

function calculateContentPages(content: string): number {
  const lines = Math.ceil(content.length / CHARS_PER_LINE);
  const contentHeight = lines * LINE_HEIGHT;
  return Math.ceil(contentHeight / CONTENT_PAGE_HEIGHT);
}
```

### 7.2 目录分页算法

```typescript
const ITEMS_PER_PAGE = 6; // 每页6个章节项

function getDirectoryPageItems(
  chapters: Chapter[], 
  page: number
): { leftItems: Chapter[], rightItems: Chapter[] } {
  const startIndex = page * ITEMS_PER_PAGE;
  const pageItems = chapters.slice(startIndex, startIndex + ITEMS_PER_PAGE);
  
  const leftItems: Chapter[] = [];
  const rightItems: Chapter[] = [];
  
  pageItems.forEach((item, index) => {
    if (index % 2 === 0) {
      leftItems.push(item);
    } else {
      rightItems.push(item);
    }
  });
  
  return { leftItems, rightItems };
}
```

## 八、交互流程

### 8.1 章节阅读流程

```
1. 进入书籍详情页 → 默认显示章节Tab的目录视图
2. 点击章节项 → 进入内容视图
3. 阅读内容 → 如有谜题可答题
4. 点击"← 目录" → 返回目录视图
5. 点击"下一章" → 直接跳转下一章内容
```

### 8.2 添加章节流程

```
1. 在目录视图点击"➕ 添加章节"
2. 跳转到故事导演页（StoryDirectorDemo）
```

## 九、设计总结

| 模块 | 布局 | 数据量 | 翻页方式 | 特殊交互 |
|------|------|--------|----------|----------|
| 章节目录 | 左右两列书页式 | 10章+添加按钮 | 底部按钮翻页 | 添加章节跳转导演页 |
| 章节内容 | 全屏单列 | 5短5长 | 底部按钮翻页/翻章 | 返回按钮回目录 |
| 角色卡牌 | 一行两个 | 5个角色 | 滚动浏览 | - |
| 情节卡牌 | 分类+一行两个 | 4类×4个=16个 | 滚动浏览 | - |
