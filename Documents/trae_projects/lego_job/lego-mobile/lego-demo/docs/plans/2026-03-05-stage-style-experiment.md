# 舞台预览风格实验方案

## 概述

为故事导演台的舞台预览区设计三种不同的视觉风格，用户可以通过切换按钮查看不同效果。

## 当前问题

- 舞台预览区使用卡片形式展示角色，显得单调
- 缺乏立体感和视觉冲击力
- 背景和场景元素不够丰富

## 三种舞台风格设计

### 风格1：3D透视舞台 (3D Perspective Stage)

#### 视觉效果
```
┌─────────────────────────────────────┐
│  🎭 舞台预览                         │
├─────────────────────────────────────┤
│                                     │
│      ╔═══════════════════════╗     │
│      ║                       ║     │
│      ║   ⚔️    🔮    🏹    ✨   ║     │  <- 3D透视排列
│      ║   ▼     ▼     ▼     ▼    ║     │  <- 阴影反射
│      ║  ═══════════════════════ ║     │  <- 舞台地板
│      ╚═══════════════════════╝     │
│                                     │
│  [背景根据天气变化]                   │
└─────────────────────────────────────┘
```

#### 技术实现
- **3D透视变换**: 使用 `transform: [{ perspective: 1000 }, { rotateX: '15deg' }]`
- **阴影反射**: 角色下方添加半透明阴影层
- **舞台地板**: 渐变色地板，模拟木质舞台
- **背景渐变**: 根据天气动态变化
  - 晴天: 金色渐变 (#FFD700 → #FFA500)
  - 雨天: 蓝色渐变 (#4A90D9 → #2C3E50)
  - 雪天: 冰蓝渐变 (#87CEEB → #E0FFFF)
  - 夜晚: 深蓝渐变 (#2C3E50 → #1a1a2e)

#### 动画效果
- 角色入场: 从舞台后方飞入
- 选中效果: 角色放大 + 发光
- 背景动画: 缓慢渐变流动

### 风格2：游戏战斗界面 (Battle Arena)

#### 视觉效果
```
┌─────────────────────────────────────┐
│  ⚔️ 战斗场景                         │
├─────────────────────────────────────┤
│                                     │
│  ┌─────┐  ┌─────┐  ┌─────┐         │
│  │ ⚔️  │  │ 🔮  │  │ 🏹  │         │  <- 角色头像框
│  │▓▓▓▓▓│  │▓▓▓░░│  │▓▓▓▓░│         │  <- 能量条
│  └─────┘  └─────┘  └─────┘         │
│                                     │
│  ✨ ✨ ✨ ✨ ✨ ✨ ✨ ✨              │  <- 动态光效粒子
│                                     │
│  [⚔️ 战斗] [☀️ 晴天] [🌲 森林]       │  <- 状态标签
└─────────────────────────────────────┘
```

#### 技术实现
- **头像框**: 圆形/六边形边框，带发光效果
- **能量条**: 根据角色类型显示不同颜色
  - 战士: 红色
  - 法师: 蓝色
  - 弓手: 绿色
  - 牧师: 黄色
  - 盗贼: 紫色
- **光效粒子**: 使用 Animated 循环动画
- **状态标签**: 底部显示当前选择的状态

#### 动画效果
- 角色入场: 从两侧滑入
- 能量条: 脉冲动画
- 光效粒子: 随机位置闪烁
- 选中效果: 头像框发光 + 能量条满格

### 风格3：沉浸式场景 (Immersive Scene)

#### 视觉效果
```
┌─────────────────────────────────────┐
│  🌲 森林探险                         │
├─────────────────────────────────────┤
│                                     │
│  ☀️ ☀️ ☀️                           │  <- 天气元素
│                                     │
│      ⚔️                             │
│           🔮                        │  <- 角色散落在场景中
│                🏹                    │
│                                     │
│  🌲 🌲 🌲 🌲 🌲 🌲 🌲 🌲            │  <- 地形装饰
│  ═══════════════════════════════    │  <- 地面
└─────────────────────────────────────┘
```

#### 技术实现
- **角色散落**: 随机位置布局，模拟自然站位
- **天气粒子**:
  - 晴天: 阳光光线
  - 雨天: 雨滴下落动画
  - 雪天: 雪花飘落动画
  - 夜晚: 星星闪烁
- **地形装饰**:
  - 森林: 树木 🌲
  - 山地: 山峰 ⛰️
  - 沙滩: 椰树 🌴
  - 沙漠: 仙人掌 🌵
- **地面纹理**: 根据地形变化

#### 动画效果
- 角色入场: 从场景边缘走入
- 天气粒子: 持续循环动画
- 角色呼吸: 轻微上下浮动
- 场景氛围: 背景缓慢变化

## 实现计划

### 1. 状态管理
```typescript
type StageStyleType = '3d-perspective' | 'battle-arena' | 'immersive-scene';

const [stageStyle, setStageStyle] = useState<StageStyleType>('3d-perspective');
```

### 2. 组件结构
```
StoryDirectorDemo.tsx
├── renderStage() - 主渲染函数
│   ├── render3DStage() - 3D透视舞台
│   ├── renderBattleArena() - 游戏战斗界面
│   └── renderImmersiveScene() - 沉浸式场景
├── renderStageStyleModal() - 风格选择弹窗
└── styles - 样式定义
```

### 3. 动画实现
- 使用 React Native Animated API
- 使用 useRef 管理动画值
- 使用 Animated.loop 创建循环动画

## 测试要点

1. 点击舞台风格按钮，打开选择弹窗
2. 选择"3D透视舞台"，验证舞台显示
3. 选择"游戏战斗界面"，验证舞台显示
4. 选择"沉浸式场景"，验证舞台显示
5. 选择角色，验证在舞台上的显示效果
6. 切换天气/地形，验证背景变化

### 视觉验证
- 三种风格切换流畅
- 动画效果明显
- 背景根据选择变化
- 角色显示正确
