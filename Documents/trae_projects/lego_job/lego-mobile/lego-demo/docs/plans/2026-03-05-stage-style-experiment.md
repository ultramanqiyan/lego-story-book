# 舞台预览风格实验方案

## 概述

为故事导演台的舞台预览区设计三种不同的视觉风格，用户可以通过切换按钮查看不同效果。

## 当前问题

- 舞台预览区使用卡片形式展示角色，显得单调
- 缺乏立体感和视觉冲击力
- 背景和场景元素不够丰富

## 三种舞台风格设计

### 风格1：3D透视舞台 (3D Perspective Stage)

#### 视觉效果
```
┌─────────────────────────────────────┐
│  🎭 舞台预览                         │
├─────────────────────────────────────┤
│                                     │
│      ╔═══════════════════════╗     │
│      ║                       ║     │
│      ║   ⚔️    🔮    🏹    ✨   ║     │  <- 3D透视排列
│      ║   ▼     ▼     ▼     ▼    ║     │  <- 阴影反射
│      ║  ═══════════════════════ ║     │  <- 舞台地板
│      ╚═══════════════════════╝     │
│                                     │
│  [背景根据天气变化]                   │
└─────────────────────────────────────┘
```

#### 技术实现
- **3D透视变换**: 使用 `transform: [{ perspective: 1000 }, { rotateX: '15deg' }]`
- **阴影反射**: 角色下方添加半透明阴影层
- **舞台地板**: 渐变色地板，模拟木质舞台
- **背景渐变**: 根据天气动态变化
  - 晴天: 金色渐变 (#FFD700 → #FFA500)
  - 雨天: 蓝色渐变 (#4A90D9 → #2C3E50)
  - 雪天: 冰蓝渐变 (#87CEEB → #E0FFFF)
  - 夜晚: 深蓝渐变 (#2C3E50 → #1a1a2e)

#### 动画效果
- 角色入场: 从舞台后方飞入
- 选中效果: 角色放大 + 发光
- 背景动画: 缓慢渐变流动

### 风格5：转盘风格 (Carousel Wheel)

#### 视觉效果
```
┌─────────────────────────────────────┐
│  🎡 转盘选择                         │
├─────────────────────────────────────┤
│                                     │
│         ╭───────────────╮          │
│        ╱   ⚔️  🔮  🏹   ╲         │  <- 旋转转盘
│       │      ✨          │         │  <- 当前选中
│        ╲   地形 天气    ╱          │  <- 其他选项
│         ╰───────────────╯          │
│              ▼                      │  <- 选中指示器
│         [当前: 战士]                │
│                                     │
│  ◄ 滑动转盘选择 ►                   │
└─────────────────────────────────────┘
```

#### 技术实现
- **转盘容器**: 使用 `transform: [{ rotate }]` 实现旋转
- **卡片布局**: 卡片均匀分布在圆形轨道上
- **透视效果**: `perspective: 800` + `rotateX` 创建3D转盘
- **惯性滑动**: 使用 `PanResponder` 实现手势滑动
- **吸附效果**: 松手后自动吸附到最近的卡片
- **颜色方案**:
  - 转盘背景: 渐变 `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`
  - 卡片背景: 半透明白色 `rgba(255,255,255,0.9)`
  - 选中高亮: 金色边框 `#FFD700`

#### 动画效果
- **旋转动画**: 使用 `Animated.spring` 实现弹性旋转
- **选中效果**: 卡片放大 + 发光 + 阴影加深
- **入场动画**: 转盘从中心放大出现
- **切换动画**: 平滑旋转到目标位置

#### 交互特点
- 左右滑动旋转转盘
- 点击卡片直接跳转
- 中心显示当前选中详情
- 底部显示快捷导航点

```
┌─────────────────────────────────────┐
│  🎮 横版冒险                         │
├─────────────────────────────────────┤
│  ☁️ ☁️      ☁️ ☁️                   │  <- 云朵背景
│                                     │
│  ⚔️ ──→  🔮 ──→  🏹 ──→  ✨        │  <- 角色横向排列
│  ═════════════════════════════════  │  <- 地面平台
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│  <- 地面砖块
│                                     │
│  [◀] [▶] 滑动选择角色               │
│  ❤️❤️❤️♡♡  金币: 120  ⭐ 3         │
└─────────────────────────────────────┘
```

#### 技术实现
- **横向滚动**: 使用 `ScrollView horizontal` 或手势滑动
- **视差背景**: 多层背景以不同速度移动
  - 远景云朵: 慢速移动
  - 中景山脉: 中速移动
  - 近景地面: 快速移动
- **平台设计**: 像素化平台砖块
- **角色状态**:
  - 待机: 轻微上下浮动
  - 选中: 跳跃动画
  - 移动: 行走动画
- **颜色方案**:
  - 天空: `#87CEEB` → `#E0F7FA`
  - 地面: `#8B4513` (棕色砖块)
  - 草地: `#228B22`

#### 动画效果
- **角色行走**: 使用帧动画或 transform 模拟
- **跳跃选中**: `Animated.sequence([translateY, scaleY])`
- **云朵飘动**: 持续缓慢移动
- **金币闪烁**: 选中时金币飞出动画

#### 交互特点
- 左右滑动浏览角色
- 点击角色触发跳跃选中
- 双击查看角色详情
- 长按拖动调整位置

### 风格7：立体书翻页风格 (Pop-up Book)

#### 视觉效果
```
┌─────────────────────────────────────┐
│  📖 立体故事书                       │
├─────────────────────────────────────┤
│  ┌─────────────────────────────────┐│
│  │     ╱╲                          ││
│  │    ╱  ╲   🏰                    ││  <- 立体城堡
│  │   ╱    ╲                        ││
│  │  ────────────────               ││  <- 书页基座
│  │    ⚔️    🔮    🏹    ✨         ││  <- 立体角色
│  │   ╱╲   ╱╲   ╱╲   ╱╲            ││  <- 立体支架
│  └─────────────────────────────────┘│
│  ◄ 前一页    [1/5]    后一页 ►     │
└─────────────────────────────────────┘
```

#### 技术实现
- **立体效果**: 使用 `transform: [{ rotateX }, { rotateY }]`
- **翻页动画**: 
  ```typescript
  Animated.timing(pageRotate, {
    toValue: -180,
    duration: 800,
    useNativeDriver: true,
  })
  ```
- **立体弹出**: 元素从平躺到立起的动画
- **阴影层次**: 根据立体高度添加阴影
- **纸张纹理**: 使用 `backgroundColor` 模拟纸张质感
- **颜色方案**:
  - 书页: `#FFF8DC` (米黄色纸张)
  - 边框: `#8B4513` (棕色皮革)
  - 阴影: `rgba(0,0,0,0.3)`

#### 动画效果
- **翻页动画**: 3D翻页效果，使用 `rotateY`
- **立体弹出**: 角色从书页"弹出"的动画
- **选中效果**: 角色向前倾斜 + 放大
- **页面切换**: 带有纸张摩擦感的动画

#### 交互特点
- 左右滑动翻页
- 点击立体元素触发动画
- 页面角落有翻页提示
- 每页展示不同场景

type StageStyleType = 
  | '3d-perspective'      // 风格1: 3D透视舞台
  | 'battle-arena'        // 风格2: 游戏战斗界面
  | 'immersive-scene'     // 风格3: 沉浸式场景
  | 'pixel-art'           // 风格4: 像素艺术风格
  | 'carousel-wheel'      // 风格5: 转盘风格
  | 'side-scroller'       // 风格6: 横版过关风格
  | 'popup-book'          // 风格7: 立体书翻页风格
  | 'holographic'         // 风格8: 全息投影风格
  | 'glassmorphism';      // 风格9: 玻璃拟态风格

const [stageStyle, setStageStyle] = useState<StageStyleType>('3d-perspective');
