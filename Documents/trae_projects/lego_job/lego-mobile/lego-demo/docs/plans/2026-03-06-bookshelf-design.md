# 书架页 UI 设计方案

## 概述

书架页采用书房/图书馆风格设计，与书籍详情页Demo的风格保持一致。书籍以竖立书本样式排列在木质书架上，营造温馨的阅读氛围。

## 交互动画设计

### 1. 书籍"抽出"动画

点击书籍时播放:
- 步骤1: 书本向右倾斜5°
- 步骤2: 书本向右平移20px (像从书架抽出)
- 步骤3: 书本放大1.05倍
- 步骤4: 显示发光边框
- 动画时长: 200ms
- 缓动函数: ease-out

### 2. 页面进入动画

书架页面进入时:
- 步骤1: 书架隔板从两侧滑入
- 步骤2: 书本依次从下往上浮入 (错开100ms)
- 步骤3: 蜡烛/粒子动画开始

### 3. 新书添加动画

创建新故事后:
- 新书卡片从上方飘落
- 插入到书架第一个位置
- 播放发光效果

### 弹窗样式

- 背景: rgba(0,0,0,0.6) 半透明遮罩
- 弹窗背景: #F5E6D3 羊皮纸色
- 边框: #8B4513 深棕色，3px
- 圆角: 12px
- 阴影: 深色投影

### 弹窗交互

- 点击遮罩: 关闭弹窗
- 输入框自动聚焦
- 空名称时"创建"按钮禁用
- 最多20个字符

## 实现要点

1. **书架布局**: 使用 Flexbox 实现两行书籍排列，每行4本
2. **书本样式**: 左侧书脊条纹 + 右侧封面区域
3. **动画效果**: 使用 React Native Animated API
4. **弹窗组件**: 使用 Modal 组件 + Animated 实现弹出动画
5. **状态管理**: 使用 useState 管理书籍列表和弹窗状态
