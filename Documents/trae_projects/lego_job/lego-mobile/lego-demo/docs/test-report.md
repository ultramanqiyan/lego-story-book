## 问题分析

### 主要问题

1. **创建书籍流程失败**
   - 创建书籍按钮选择器未匹配
   - 导致后续所有依赖书籍创建的测试失败

2. **选择器编码问题**
   - 部分中文选择器在Appium中出现乱码
   - 需要使用更稳定的选择器策略

3. **首页返回验证失败**
   - "LEGO Story"选择器在某些情况下未匹配

### 建议改进

1. **使用更稳定的选择器**
   - 使用`resource-id`或`accessibility-id`代替文本选择器
   - 添加元素等待时间

2. **独立测试用例**
   - 减少测试用例之间的依赖关系
   - 每个测试用例应该能够独立运行

3. **增加错误处理**
   - 添加更详细的错误日志
   - 失败时截图保存
