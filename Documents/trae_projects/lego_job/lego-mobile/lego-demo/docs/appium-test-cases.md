## 快速启动脚本

### 1. 启动模拟器

```powershell
powershell -ExecutionPolicy Bypass -File start-emulator.ps1
```

### 2. 构建APK

```powershell
powershell -ExecutionPolicy Bypass -File build-apk.ps1
```

### 3. 安装APK

```powershell
powershell -ExecutionPolicy Bypass -File install-apk.ps1
```

### 4. 运行APP

```powershell
powershell -ExecutionPolicy Bypass -File run-app.ps1
```

### 5. 运行测试

```bash
node appium-full-test.js
```

## 卡牌掉落机制说明

### 新建书籍时的初始解锁

创建新书籍时，系统会自动解锁以下元素：

| 类型 | 数量 | 说明 |
|------|------|------|
| 角色 | 2个 | 随机选择该类型的2个角色 |
| 天气 | 2个 | 随机选择该类型的2个天气 |
| 地形 | 2个 | 随机选择该类型的2个地形 |
| 装备 | 2个 | 随机选择该类型的2个装备 |
| 冒险 | 2个 | 随机选择该类型的2个冒险 |

### 解谜成功后的卡牌掉落

解谜成功后，系统会：

1. 调用 `getLockedElements(bookId, typeId)` 获取未解锁的元素
2. 如果存在未解锁元素，随机选择一个进行解锁
3. 显示解锁弹窗

### 可能不掉落卡牌的情况

- 所有该类型的元素都已解锁
- `getLockedElements` 返回空数组

## 常见问题

### Q1: Appium服务器启动失败

**解决方案：**
```bash
# 检查Appium是否安装
npm list -g appium

# 重新安装Appium
npm install -g appium
```

### Q2: 模拟器连接失败

**解决方案：**
```bash
# 检查模拟器状态
adb devices

# 重启ADB服务
adb kill-server
adb start-server
```

### Q3: APK安装失败

**解决方案：**
```bash
# 卸载旧版本
adb uninstall com.legostory.demo

# 重新安装
adb install android/app/build/outputs/apk/debug/app-debug.apk
```
