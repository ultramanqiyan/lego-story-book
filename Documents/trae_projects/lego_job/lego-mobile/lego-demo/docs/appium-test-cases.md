## 快速启动

### 1. 启动模拟器

```powershell
powershell -ExecutionPolicy Bypass -File start-emulator.ps1
```

### 2. 构建APK

```powershell
powershell -ExecutionPolicy Bypass -File build-apk.ps1
```

### 3. 安装APK

```powershell
powershell -ExecutionPolicy Bypass -File install-apk.ps1
```

### 4. 运行测试

```bash
node appium-full-test.js
```

## 已知问题

### 1. 章节点击测试失败

**原因：** 章节列表元素选择器不匹配

**解决方案：** 更新选择器以匹配实际UI元素

### 2. 卡牌展示区测试失败

**原因：** 测试脚本选择器与实际UI文本不匹配

**解决方案：** 更新选择器为 `//*[contains(@text, "解锁卡牌") or contains(@text, "本章卡牌")]`

### 3. 解谜场景测试失败

**原因：** 需要先进入章节才能测试解谜功能

**解决方案：** 添加进入章节的前置步骤

## 常见问题

### Q1: Appium服务器启动失败

**解决方案：**
```bash
# 检查Appium是否安装
npm list -g appium

# 重新安装Appium
npm install -g appium
```

### Q2: 模拟器连接失败

**解决方案：**
```bash
# 检查模拟器状态
adb devices

# 重启ADB服务
adb kill-server
adb start-server
```

### Q3: APK安装失败

**解决方案：**
```bash
# 卸载旧版本
adb uninstall com.legostory.demo

# 重新安装
adb install android/app/build/outputs/apk/debug/app-debug.apk
```
