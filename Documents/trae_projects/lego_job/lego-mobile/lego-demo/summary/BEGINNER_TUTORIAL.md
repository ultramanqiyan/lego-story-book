## 第一章：开发环境搭建

### 1.1 安装Node.js

#### 什么是Node.js？
Node.js是JavaScript的运行环境，就像手机需要操作系统才能运行APP一样，JavaScript代码需要Node.js才能运行。

#### 安装步骤

**第一步：下载Node.js**
1. 打开浏览器，访问Node.js官网
2. 选择LTS（长期支持）版本下载
3. LTS版本更稳定，适合初学者

**第二步：安装Node.js**
1. 双击下载的安装文件
2. 按照安装向导的提示，一直点击"下一步"
3. 不需要修改任何默认设置
4. 最后点击"完成"

**第三步：验证安装**
1. 打开命令行工具（Windows按Win+R，输入cmd）
2. 输入命令查看版本：`node --version`
3. 如果显示版本号（如v18.17.0），说明安装成功

#### 注意事项
- 安装过程中保持网络连接
- 不要修改默认安装路径，除非你知道自己在做什么
- 安装完成后需要重启命令行工具

### 1.2 安装代码编辑器

#### 推荐使用VS Code
Visual Studio Code是最流行的代码编辑器，免费且功能强大。

#### 安装步骤

**第一步：下载VS Code**
1. 访问VS Code官网
2. 点击下载按钮
3. 选择适合你系统的版本

**第二步：安装VS Code**
1. 双击安装文件
2. 接受许可协议
3. 选择安装位置（建议默认）
4. 在"选择附加任务"页面，勾选以下选项：
   - 添加"通过Code打开"到右键菜单
   - 将Code注册为支持的文件类型的编辑器
5. 点击安装

**第三步：安装推荐插件**
打开VS Code后，点击左侧的扩展图标，搜索并安装：
- Chinese Language Pack（中文语言包）
- ES7+ React/Redux/React-Native snippets
- TypeScript Importer

### 1.3 安装Expo CLI

#### 什么是Expo？
Expo是一个简化React Native开发的工具，就像游戏引擎简化游戏开发一样，Expo让我们更容易开发手机APP。

#### 安装步骤

**第一步：打开命令行**
- Windows：按Win+R，输入cmd，回车

**第二步：安装Expo CLI**
在命令行中输入安装命令，等待安装完成。这个过程可能需要几分钟。

**第三步：验证安装**
输入命令查看版本，确认安装成功。

### 1.4 安装Android Studio（可选）

#### 为什么需要Android Studio？
如果你想在Android模拟器上测试应用，需要安装Android Studio。

#### 安装步骤

**第一步：下载Android Studio**
1. 访问Android开发者官网
2. 下载Android Studio
3. 文件较大（约1GB），请耐心等待

**第二步：安装Android Studio**
1. 双击安装文件
2. 选择安装组件（保持默认即可）
3. 选择安装位置
4. 等待安装完成

**第三步：配置Android模拟器**
1. 打开Android Studio
2. 点击"More Actions" → "Virtual Device Manager"
3. 点击"Create Device"
4. 选择一个设备型号（推荐Pixel 6）
5. 选择系统镜像（推荐API 34）
6. 完成创建

## 第三章：核心功能开发

### 3.1 理解游戏架构

#### 游戏的核心概念
在开始编码前，我们需要理解游戏的核心概念：

**1. 游戏状态**
- 当前回合数
- 玩家和对手的生命值
- 当前法力值
- 手牌列表
- 场上随从

**2. 卡牌系统**
- 卡牌名称
- 卡牌费用
- 攻击力和生命值
- 卡牌类型（随从/法术）

**3. 游戏流程**
- 玩家回合开始
- 抽牌
- 打出卡牌
- 结束回合
- 对手回合

### 3.2 开发游戏状态管理

#### 第一步：定义游戏状态
我们需要定义一个数据结构来存储游戏的所有状态信息。

**思考过程**：
1. 游戏需要哪些数据？
   - 双方生命值
   - 当前法力值
   - 手牌
   - 场上随从
   - 回合数

2. 如何组织这些数据？
   - 使用对象（Object）来组织
   - 每个数据都有清晰的名称

#### 第二步：创建状态管理逻辑
使用React的useState来管理游戏状态。

**为什么使用useState？**
- useState是React提供的状态管理工具
- 当状态改变时，界面会自动更新
- 就像Excel表格，数据改变，图表自动更新

#### 第三步：实现状态更新函数
创建函数来更新游戏状态，比如：
- 打出卡牌
- 召唤随从
- 攻击
- 结束回合

### 3.3 开发卡牌系统

#### 第一步：定义卡牌数据

- 唯一ID
- 卡牌名称
- 费用
- 攻击力
- 生命值
- 卡牌描述
- 卡牌类型

创建一个卡牌数据库，包含所有卡牌的信息。

#### 第三步：实现卡牌渲染
将卡牌数据渲染成可视化的UI组件。

- 卡牌大小适中，方便点击

### 3.4 开发交互系统

## 第四章：风格系统开发

### 4.1 理解风格系统

#### 什么是风格系统？
风格系统就像换皮肤，可以改变游戏的视觉外观，但不改变游戏玩法。

#### 风格包含什么？
- 颜色方案
- 边框样式
- 阴影效果
- 背景图案
- 文字样式

### 4.2 设计风格配置

#### 第一步：确定风格属性
每个风格需要定义：
- 主色调
- 次要色调
- 强调色
- 背景色
- 边框色
- 文字颜色
- 圆角大小
- 阴影配置

#### 第二步：创建风格数据
为每种风格创建详细的配置数据。

**设计思路**：
- 经典风格：深蓝+金色，传统炉石风格
- 暗黑风格：黑色+红色，神秘暗黑系
- 赛博朋克：紫色+青色，科技感
- 水墨风格：白色+黑色，中国风
- 卡通风格：黄色+橙色，活泼可爱

#### 第三步：实现风格切换
创建风格切换逻辑，让玩家可以实时切换风格。

### 4.3 开发风格管理器

#### 第一步：创建风格上下文
使用React Context来管理全局风格状态。

**为什么使用Context？**
- Context可以在整个应用中共享数据
- 不需要一层层传递props
- 类似全局变量，但更安全

#### 第二步：实现风格切换函数
创建函数来切换当前使用的风格。

#### 第三步：应用风格到组件
将风格配置应用到UI组件上。

**应用方式**：
- 使用style属性
- 动态读取风格配置
- 自动更新UI

### 4.4 开发风格选择UI

#### 第一步：设计选择界面
- 弹窗式设计
- 横向滚动列表
- 每个风格一个选项卡

#### 第二步：实现选择逻辑
- 点击风格选项
- 更新当前风格
- 关闭选择界面

#### 第三步：添加视觉反馈
- 当前选中的风格高亮显示
- 切换时有过渡动画
- 提供风格名称和预览

## 第五章：动画系统开发

### 5.1 理解动画原理

#### 动画的基本概念
动画 = 一系列连续的画面，快速播放形成运动效果

#### 动画的类型
- 入场动画：卡牌进入游戏
- 出场动画：卡牌离开游戏
- 交互动画：点击、拖拽反馈
- 状态动画：生命值变化、法力值变化

### 5.2 设计动画效果

#### 第一步：确定动画类型
本项目实现了10种动画效果：

1. **弹跳进入**：卡牌从上方弹跳进入
2. **翻转进入**：卡牌翻转后显示
3. **滑入效果**：卡牌从侧面滑入
4. **旋转进入**：卡牌旋转后出现
5. **渐变闪烁**：卡牌闪烁发光
6. **脉冲效果**：卡牌有节奏地缩放
7. **摇晃效果**：卡牌左右摇晃
8. **波浪效果**：卡牌上下浮动
9. **粒子爆发**：粒子从中心爆发
10. **光环效果**：光环从中心扩散

#### 第二步：定义动画参数
每个动画需要定义：
- 持续时间
- 动画曲线
- 重复次数
- 延迟时间

### 5.3 实现动画引擎

#### 第一步：选择动画库
使用React Native Reanimated库，它是专门为React Native设计的高性能动画库。

**为什么选择Reanimated？**
- 性能优秀，动画流畅
- API简单易用
- 支持复杂动画
- 社区活跃

#### 第二步：创建动画函数
为每种动画创建专门的函数。

**函数设计思路**：
- 输入：动画参数
- 处理：执行动画逻辑
- 输出：动画效果

#### 第三步：实现动画控制
创建动画控制接口，可以：
- 开始动画
- 停止动画
- 暂停动画
- 重置动画

### 5.4 开发动画选择UI

#### 第一步：设计选择界面
- 与风格选择类似的界面
- 动画效果预览
- 当前选中动画高亮

#### 第二步：实现选择逻辑
- 点击动画选项
- 更新当前动画
- 提供即时预览

#### 第三步：添加动画预览
- 在选择界面显示动画效果
- 提供动画名称和图标
- 方便用户选择

- 提高测试效率
- 避免重复劳动
- 可以频繁执行
- 发现人工难以发现的问题

### A. 术语表

**React**：用于构建用户界面的JavaScript库

**Expo**：简化React Native开发的工具平台

**组件**：可复用的UI单元

**状态**：组件的数据

**Props**：父组件传递给子组件的数据

**Context**：React的全局状态管理工具

**动画**：连续变化的视觉效果

**Appium**：自动化测试工具

### B. 快速参考

**常用命令**：
- 启动开发服务器：`npx expo start`
- 运行Android版本：`npx expo start --android`
- 运行Web版本：`npx expo start --web`
- 安装依赖：`npm install`
- 运行测试：`node test-script.js`

**常用快捷键**：
- 重新加载：按 `r` 键
- 打开开发者菜单：按 `m` 键
- 切换平台：按 `a` (Android) 或 `w` (Web)
