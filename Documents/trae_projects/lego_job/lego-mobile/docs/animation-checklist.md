# 动画效果提升检查清单

## 验收标准
每个动画效果需满足以下标准才算完成：
- ✅ 动画流畅（60fps）
- ✅ 视觉效果明显且差异化
- ✅ 符合物理规律（弹性、惯性）
- ✅ 不影响页面性能
- ✅ 移动端触摸反馈正常

---

## 全局动画系统

### 粒子系统
- [ ] 粒子形状多样化（星形、菱形、圆形）
- [ ] 粒子大小随机变化（2px-8px）
- [ ] 粒子颜色渐变（金色→紫色→蓝色）
- [ ] 发光效果（box-shadow glow）
- [ ] 曲线运动轨迹
- [ ] 闪烁效果（opacity pulsing）

### 背景光晕
- [ ] 渐变光晕缓慢移动
- [ ] 金色、紫色交替
- [ ] 光晕大小变化

### 触摸反馈
- [ ] 点击产生涟漪
- [ ] 涟漪颜色与主题匹配
- [ ] 涟漪扩散后淡出
