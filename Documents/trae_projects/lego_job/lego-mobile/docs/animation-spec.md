# Demo动画效果提升规格说明

## 项目概述
作为专业APP端UI动画特效师，对现有的5个Demo页面进行明显的、差异化的动画效果提升，使动画更加生动、流畅、具有视觉冲击力。

## 设计理念
- **微交互**：每个用户操作都有即时反馈
- **物理感**：动画遵循自然物理规律（重力、弹性、惯性）
- **层次感**：多层次动画叠加创造深度
- **戏剧性**：关键时刻有强烈的视觉冲击

## 技术实现要点

### CSS动画属性
```css
/* 弹性缓动 */
--bounce-easing: cubic-bezier(0.68, -0.55, 0.265, 1.55);

/* 平滑缓动 */
--smooth-easing: cubic-bezier(0.4, 0, 0.2, 1);

/* 入场缓动 */
--enter-easing: cubic-bezier(0, 0, 0.2, 1);

/* 退出缓动 */
--exit-easing: cubic-bezier(0.4, 0, 1, 1);
```

### 关键帧动画命名规范
- `fadeIn*` - 淡入类动画
- `slideIn*` - 滑入类动画
- `bounce*` - 弹跳类动画
- `pulse*` - 脉冲类动画
- `float*` - 浮动类动画
- `glow*` - 发光类动画
- `rotate*` - 旋转类动画
- `scale*` - 缩放类动画

### 性能优化
- 使用 `transform` 和 `opacity` 进行动画（GPU加速）
- 避免动画 `width`、`height`、`margin` 等属性
- 使用 `will-change` 提示浏览器优化
- 控制同时运行的动画数量
