# 移动端与网页端界面同步规格说明

## 一、背景

当前移动端(React Native)界面与网页端存在明显差异，需要将移动端界面调整为与网页端一致的桌游/卡牌游戏风格。

## 二、网页端设计特点

### 2.1 颜色方案
- **背景色**: 深色渐变 (#0d0d14 → #1a1a2e → #252542)
- **主色调**: 金色 (#ffd700 / #b8860b)
- **次要色**: 紫色 (#a855f7)、深蓝 (#3b82f6)
- **文字色**: 主文字 #f8fafc，次文字 #94a3b8
- **角色类型色**: 主角金色、反派深红、配角银色、冒险紫色

### 2.2 卡片设计
- **炉石传说风格卡牌**: 3:4比例，圆角12px，3px边框
- **卡片结构**: 角色标签 + 头像区域 + 名称横幅 + 属性宝石
- **悬停效果**: 上浮15px + 放大1.08倍 + 发光效果

### 2.3 按钮设计
- **主按钮**: 金色渐变背景，圆角25px，脉冲发光动画
- **次要按钮**: 镂空设计，金色边框

### 2.4 动画效果
- 粒子漂浮效果
- 标题闪烁效果
- 卡片悬停动画
- 按钮脉冲动画

### 2.5 特殊UI元素
- 宝石形状统计图标
- 3D书本图标
- 罗马数字章节徽章
- 角色属性宝石(攻击力/生命值)

## 三、移动端当前状态

### 3.1 颜色方案
- 背景色: #FFF8E7 (浅黄色)
- 主色调: #FFD100 (乐高黄)
- 缺少深色背景和渐变效果

### 3.2 卡片设计
- 简单的白色卡片
- 缺少角色类型边框区分
- 缺少属性宝石显示

### 3.3 按钮设计
- 基本的黄色按钮
- 缺少发光动画效果

### 3.4 动画效果
- 无动画效果

## 五、技术实现

### 5.1 颜色系统重构
```javascript
const COLORS = {
  // 背景色
  bgDark: '#0d0d14',
  bgMedium: '#1a1a2e',
  bgLight: '#252542',
  
  // 主色调
  gold: '#ffd700',
  goldDark: '#b8860b',
  purple: '#a855f7',
  blue: '#3b82f6',
  
  // 角色类型色
  protagonist: '#ffd700',  // 主角-金色
  antagonist: '#dc2626',   // 反派-深红
  supporting: '#c0c0c0',   // 配角-银色
  adventure: '#a855f7',    // 冒险-紫色
  
  // 文字色
  textPrimary: '#f8fafc',
  textSecondary: '#94a3b8',
  textMuted: '#64748b',
};
```

### 5.2 动画实现
- 使用 React Native Animated API
- 使用 react-native-reanimated 实现复杂动画

### 5.3 卡片组件重构
- 创建 HSCard 组件（炉石风格卡片）
- 创建 GemIcon 组件（宝石图标）
- 创建 ChapterBadge 组件（章节徽章）
